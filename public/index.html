quick start

this panel controls an NFT minting stack: 20+ EVM wallets, multi-chain RPC fan-out, offline pre-signing, private relay broadcast, solana wallets, and post-mint tracking. everything runs on this server — the panel is just the cockpit.

  1. wallets — generate or import wallets. fund the ones you'll mint with.
  2. chains — verify RPC endpoints per chain. add more if a drop is on an unsupported chain.
  3. mint / mass / flash — pick a mode (below) and fire.
  4. pnl — scan chain history to track cost / realized / unrealized.

mint modes — when to use which

mintnormaldrop is already live, no competition, just minting

flash mint — the fastest flow

three phases, matching the reference fastest-mint flow:

  1. prep — sign offline. resolve the drop, rank the rpc pool by latency, build and sign every tx before the drop opens. nothing touches the chain yet. when the chip shows N armed, txs are ready.
  2. arm (hot window). enter the drop start (unix seconds) and a lead (seconds before start). the server sleeps until start − lead then fires automatically — no button mashing, no human latency.
  3. fire. broadcast all signed txs simultaneously:
    • fanout — every tx to every ranked rpc, first receipt wins. fastest public path.
    • flashbots — private relay, zero frontrun risk, lands in next block.
    • both — flashbots first, fanout as fallback.

price ceiling guard — set a max eth/nft before firing. at fire time the live drop price is re-read from the fastest rpc; if the dev raised the price above your cap, the fire aborts automatically and the plan is kept for a manual decision. prevents gas burn on bait-and-switch drops.

wl eligibility — check which of your wallets are allowlisted for a collection before the drop. uses the OpenSea eligibility API, falls back to an on-chain merkle-root probe. results show [WL] / [--] / [??] per wallet.

drop watcher — paste a drop page url to check status (sold out / live / upcoming / allowlist / price). watch mode polls the page and fires a webhook when the phase flips.

wallets

  • generate — creates fresh wallets server-side (keys stay on this machine, never leave it).
  • import — add an existing wallet by private key.
  • fund — send eth to each wallet before minting (check the price per nft × qty × wallet count + gas buffer).
  • delete removes by address. there is no recovery from a deleted wallet — sweep funds out first.

chains & rpc

  • each chain has a pool of rpc endpoints. the pool is latency-ranked before every fire — the fastest endpoint gets the broadcast.
  • rank — health-check all endpoints for a chain. run this before a drop to prune dead/slow endpoints.
  • add custom endpoints (alchemy, infura, quicknode, or free public ones) per chain in the chains tab.

proxies

  • http/socks5 proxies for api calls (rarity, wl checks, drop watching) — keeps api rate limits off your server ip.
  • sticky assignment — each wallet keeps the same proxy across runs, mimicking a consistent identity.

sweep

  • batch-transfer all erc-721 / erc-1155 holdings from many wallets to one destination wallet.
  • typical flow after minting: sweep the nfts to a vault wallet, then drain remaining eth.
  • runs are idempotent — already-transferred tokens are skipped.

rarity

  • pulls collection stats + per-token rarity rank (OpenSea api, cached 15 min).
  • use after minting to decide what to list vs hold — high-rank pieces often list above floor.

solana

  • separate wallet set (generate / import), sol balance check, sol transfers, nft account lookup.
  • defaults to the public mainnet rpc (rate limited) — set SOLANA_RPC (helius / quicknode free tier) in settings for serious use.

pnl

  • scan — reads chain transfer history per wallet: mint (transfer from 0x0) = acquisition cost (price + gas), transfers out = realized.
  • positions update automatically after each successful flash fire.
  • manual sale entry for off-chain deals.

jobs & activity

  • jobs — every operation (prep, fire, sweep, scan) runs as a background job with live logs. check here when something fails.
  • activity — server log stream (socket.io). wake timers and guard decisions log here in real time.

settings

  • webhooks — discord / telegram notifications for mints, fires, phase flips.
  • captcha keys — capsolver / 2captcha for gated drops.
  • opensea key — auto-refreshed daily by the server (7-day instant keys, self-healing).

tips & troubleshooting

  • insufficient funds on fire — wallet gas dust; fund more or lower qty.
  • prep 0 signed — drop not resolved (wrong contract/slug) or all wallets underfunded; check job logs.
  • price ceiling abort — live price exceeded your cap; dev raised the price. re-check the drop, adjust or remove the cap.
  • rpc all dead — run rank; add endpoints in chains.
  • receipt never lands — tx likely reverted on-chain (sold out mid-flight). check the tx hash on a explorer.
  • server — systemd unit minter: systemctl restart minter · logs: journalctl -u minter -f.
